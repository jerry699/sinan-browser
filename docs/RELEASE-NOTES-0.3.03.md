# 司南浏览器 0.3.03 · 引擎大版本升级（Chromium 159）

司南（Sinan）——面向中国用户的本地 AI 浏览器。**AI 悄悄帮忙，不改变浏览**：所有 AI 功能在本地小模型上运行，数据不出你的 Mac；AI 部分完全选装。

## 本版本三大变更

### 1. 引擎升级：Chromium 156 → 159.0.8154.13
上游 Cra 把引擎从「修补版 CEF」迁移到了**完整 Chromium 构建**（Cra Framework），司南跟进切换：
- 跨三个大版本的安全修复与网站兼容性
- 上游 Engine 发布两日内迭代 8 版的稳定性修复（扩展弹窗、无痕窗口、安全连接、暗色模式等）
- Intel 版与 Apple Silicon 版都使用同一套上游引擎（Intel 版即我们当年 PR #235 争取到的 macosx64 支持）

### 2. 上游 513 项同步：新架构 + 新设计
- **标签整理精度升级**：模型回答协议改为逐标签指派（#594，实测零错组），提示词按字节预算拟合（4K 上下文不再溢出——修复「多标签不分类」）
- **命令栏性能**：索引改为开栏时离线构建（#617），数千标签下首键即响应；档案隔离（#609）
- **iPhone 设计编目**（36 项提交）：搜索 sheet 手势、底栏手势等已归档为鸿蒙版设计参考库
- 司南本地 AI 栈完整移植到新架构：整理三件套、语义搜索（RRF 融合）、划选翻译、音视频蒸馏、自动整理、P5 偏好记忆（域级规则 + ⌘Z 只撤当次教训）

### 3. 品牌完成：最后一处 "Cra" 已清零
可执行文件、崩溃对话框、系统通知、更新窗口、应用菜单、性能洞察——全部「司南」。

## 已知边界
- Apple Silicon 版为首次交叉构建（未在 M 芯片实机测试），遇到问题请开 Issue
- 引擎切换到上游 Chromium 构建后，右键菜单的「划选翻译 / 蒸馏媒体」入口暂缺（钩子在引擎框架内，下版补）；蒸馏功能本身可用
- 引擎路径下的 Chromium 数据缓存首次启动会重建（浏览历史不受影响）

## 升级方式
已安装 0.3.00-0.3.02 的用户：菜单 司南 ▸ 检查更新（Intel 与 Apple Silicon 走独立更新通道）。数据、模型、整理记忆全部保留。
